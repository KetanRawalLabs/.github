# Support

For help using a project, first check its README, documentation, and existing issues. Include the repository, version, environment, the steps you tried, and relevant sanitized error messages.

Use GitHub Issues for reproducible bugs or documentation corrections. For general questions, use GitHub Discussions if that repository has them enabled. Choose the issue type that best fits and keep requests focused.

Do not post passwords, tokens, personal data, or security vulnerabilities publicly. See SECURITY.md for vulnerability reports.

KetanRawalLabs repositories are maintained as time permits. Support response times are not guaranteed; project-specific support commitments, if any, are stated in that project's documentation.
