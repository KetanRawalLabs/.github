# Security policy

We take reports about security vulnerabilities seriously.

## Reporting a vulnerability

Do not report vulnerabilities in public issues, discussions, or pull requests. If private vulnerability reporting is enabled for the affected repository, use GitHub's private reporting option. Otherwise, contact the repository maintainers through the KetanRawalLabs organization profile with a concise description and a way to reproduce the issue safely.

Please include the affected repository and version or commit, impact, reproduction steps, and any suggested mitigation. Do not include real credentials or personal data. We will acknowledge reports when possible, assess impact, and coordinate a fix and disclosure with the reporter. Response and fix times depend on severity and maintainer availability.

Each project may provide a more specific security contact or policy in its own SECURITY.md.
