# KetanRawalLabs GitHub standards

This special repository publishes our organization profile and shared community guidance. Files here provide defaults for repositories that do not contain their own versions.

## Before creating a repository

1. Create it under the KetanRawalLabs organization when it belongs to the AI product portfolio.
2. Choose a clear name, accurate description, topics, and visibility.
3. Follow the [repository standards](REPOSITORY_STANDARDS.md).
4. Write a project-specific README, setup steps, and operating requirements.
5. Link the repository’s issues to the [AI Portfolio project](https://github.com/orgs/KetanRawalLabs/projects/1) when they need cross-project tracking.
